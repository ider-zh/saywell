# Saywell

![Saywell](assets/branding/saywell-github-banner.jpg)

**简体中文 · [English](README.en.md)**

在你输入的地方，获得翻译、润色和词汇提示。

写英文消息时拿不准怎么表达？先用中文写下想法，或直接输入英文，Saywell 会在你停顿时给出建议。你可以保留原文、复制结果，或者点击「应用」替换；它不会替你发送消息。

适用于 Chrome 和 Edge。**目前是预览版，尚未上架 Chrome Web Store。**

## 安装并开始使用

1. 在[版本下载页面](https://github.com/ider-zh/saywell/releases)下载 `saywell-版本号.zip`，不要选择 Source code。若尚无已发布版本，或想测试最新改动，可打开[预览构建](https://github.com/ider-zh/saywell/actions/workflows/build.yml)，选择成功的构建，在 **Artifacts** 下载安装包；此下载需要登录 GitHub。
2. 解压到一个以后不会随意移动的文件夹。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 欢迎页打开后，阅读处理说明，点击 **「同意并启用 Saywell」**，批准浏览器的网页访问权限。
5. 回到普通网页，在输入框中写一句话并停顿。更新或已打开的页面可能需要刷新一次。

**基础免费 AI 不需要账号或 API Key，一步授权即可使用。** 如果拒绝授权，工具栏会显示 `!`；可点击重新申请，也可以在设置或弹窗中只启用当前网站。

## 翻译、润色，然后由你决定

- **中英互译**：默认将中文译为英文；点击浏览器工具栏的 Saywell 图标，可以切换目标语言。
- **润色表达**：输入目标语言时，自动提供更自然的表达。也可以在浮窗中选择翻译、润色或解释。
- **先看到可用结果**：浏览器本地翻译可用，或你连接了机器翻译服务时，它会与 AI 同时处理。AI 结果到达后，较早的机器翻译结果会折叠，仍可展开查看。
- **主动应用**：点击「应用」才会替换原文。输入内容已经变化时，不会用旧结果覆盖新文字；部分复杂输入框提供「复制」。

手动触发建议的快捷键是 **Alt + Shift + E**；macOS 为 **Command + Shift + E**。

## 把建议变成自己的表达

在结果下方点击「练习这句话」，直接在浮窗中重输一次。文字差异会高亮，大小写和标点差异会用较轻的样式显示。练习不会改动网页草稿，也不会上传或保存你的练习输入。

英文结果中的词汇提示可展开查看释义、例句并加入收藏。附带原句语境需要你另外勾选同意。

## 让浮窗适合你的习惯

浮窗支持小、中、大三种尺寸，也可以拖动标题栏。手动移动后，迷你图钉表示位置已记住；点击图钉即可恢复自动定位。

暂时不需要建议时，点击小钟，暂停 **1 小时、4 小时或到明天零点**，可作用于当前网站或所有网站。也能在「网站设置」中屏蔽当前网站，或为它单独选择目标语言、默认操作和服务配置。

界面支持中文和英文，默认跟随浏览器。界面语言与翻译目标语言分别设置。

## 历史记录和隐私

从侧栏或扩展弹窗进入「翻译历史」，可搜索、删除、清空和导出最近的翻译。默认滚动记录 **100 条**，可以调整数量或关闭记录。

**默认只在当前浏览器会话保留历史、词汇和统计。** 浏览器重启，或扩展被重新加载、更新、停用后，会话数据会消失。需要长期保留时，可在设置中创建「本地保险库」：数据加密保存在本机，重启后输入密码解锁。记住 API Key 也需要已解锁的保险库。忘记密码无法找回数据，请妥善保管。

授权远程处理后，停止输入可能自动将**当前输入框的完整草稿**发送给连接的服务。默认免费 AI 由 Cloudflare Workers AI 处理；浏览器本地翻译不上传文本。连接多家服务并启用回退时，同一句话可能发送给多家已授权服务。

密码框和常见敏感字段会被排除，但普通文本框中的机密内容无法全部识别。请在敏感网站暂停或加入黑名单。历史记录包含原文和结果；本地统计只记录数字汇总和网站域名，可以单独关闭。没有广告或云端历史同步。

阅读完整[中文隐私政策](docs/privacy-policy.zh-CN.md) · [English Privacy Policy](docs/privacy-policy.en.md)。

## 免费服务与自选服务

Saywell 免费 AI 有共享每日额度，北京时间 **08:00** 重置。额度耗尽时会提示；本地机器翻译或你另行连接的机器翻译服务仍可在支持时使用。免费额度和服务可能调整，不承诺无限或永久免费。

如果你已有服务账号，可以在设置中添加 OpenAI、DeepSeek、小米 MiMo、硅基流动、Gemini、Ollama 或兼容服务，保存多组配置并选择使用哪一组。机器翻译可另行连接 MyMemory、LibreTranslate、Google Cloud 或 Microsoft Azure。各服务的费用和数据规则由相应服务商决定。

## 常见问题

**没有出现建议？** 确认已授权网页访问、当前网站没有被屏蔽或暂停，然后刷新页面。浏览器内部页面、扩展商店等受限页面无法使用。

**大模型提示未连接？** 在设置中选中相应配置，点击「连接并测试」。自选服务可能需要重新填写密钥；保存过的密钥在保险库锁定时需要先解锁。

**机器翻译没有结果？** 浏览器本地翻译取决于版本和语言模型准备情况；其他机器翻译服务需要单独连接。免费 AI 可以独立提供翻译和润色。

**如何更新？** 将新版文件解压覆盖到原来的扩展文件夹，在扩展管理页点击 Saywell 的「重新加载」，再刷新网页。需要保留私有记录时，请先创建保险库；仅会话数据会在重新加载时清除。

**如何迁移设置？** 在设置中的「配置备份」导出或导入。备份不含密钥、保险库或历史，导入后按提示重新连接服务。

**发现问题或有建议？** 到[问题反馈](https://github.com/ider-zh/saywell/issues)描述网站、浏览器和操作步骤。请勿贴出私人原文或 API Key。
