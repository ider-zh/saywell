# Saywell

**[简体中文](README.md) · [English](README.en.md)**

[![自动构建](https://github.com/ider-zh/saywell/actions/workflows/build.yml/badge.svg)](https://github.com/ider-zh/saywell/actions/workflows/build.yml)

在你输入的地方，获得翻译、润色和词汇提示。

Saywell 是面向 Chrome 和 Edge 的浏览器扩展。它将中文或中英混合输入翻译成英文，也能反向翻译为中文；在你写英文时提供润色和表达建议。机器翻译与大模型并行处理，帮助你先看到结果，再逐步改善表达。

目前为开发预览版，通过解压加载安装，尚未上架扩展商店。

## 安装：一次授权即可开始

1. 打开 [自动构建页面](https://github.com/ider-zh/saywell/actions/workflows/build.yml)，选择最新成功的构建，在 **Artifacts** 下载 `saywell-版本号.zip`。下载构建产物需要登录 GitHub。
2. 解压 ZIP。在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
4. 安装后欢迎页会自动打开，点击 **「授权并开始使用」**，确认浏览器的网页访问权限申请。
5. 在普通网页输入框中输入文字并短暂停顿，即可获得建议。也可按 **Alt + Shift + E** 手动触发；macOS 为 **Command + Shift + E**。

首次授权会一起启用免费 AI 翻译、润色、词汇提示和免费机器翻译，无需账号或 API Key。授权前会说明文本将发送给哪些服务。已有普通网页会在浏览器允许时直接启用；更新扩展后请刷新网页，以加载新版脚本。

如果拒绝授权或之后撤销权限，工具栏图标会显示 **!**，设置页和扩展弹窗也会显示提醒。点击授权按钮即可重新申请。

也可以[从源码构建](#从源码构建)后加载本地 `dist/` 目录。

## 日常使用

- **翻译与润色**：默认自动判断输入语言，目标语言默认英文。点击扩展图标可切换 English / 英文或 Chinese / 中文；同语种输入由大模型润色，也可在浮窗选择翻译、润色或解释。
- **先看到结果**：机器翻译和大模型同时运行。有可用结果才显示浮窗；大模型结果到达后成为主结果，机器翻译收进默认折叠区域。某一路失败时保留另一路结果。
- **由你决定修改**：点击「应用」才会替换输入框内容，不会自动发送消息或提交表单。替换前会再次检查原文；不支持安全替换的复杂编辑器提供「复制」。
- **词汇提示**：英文结果最多提示 3 个词或短语，可查看释义、例句，标记已掌握或加入复习。在词汇收藏中附带原句需要另行勾选同意。
- **可移动浮窗**：拖动标题栏调整位置，小／中／大三种尺寸可随时切换。位置和尺寸按网站域名单独记忆，并在浏览器缩放窗口后保持可见。
- **位置图钉**：手动移动后，标题栏会出现迷你图钉，表示已记住此网站的位置；点击即可取消固定，恢复随输入框自动定位。
- **临时暂停**：点击浮窗标题栏的小钟，选择 1 小时、4 小时或到本机明天零点，作用于当前网站或所有网站。暂停期间停止建议和输入统计；到期恢复，也可在扩展弹窗提前解除。
- **句子练习**：点击建议下方的「练习这句话」，在浮窗内重新输入。红色突出文字差异，虚线弱化大小写、空格和标点差异；练习期间锁定所选句子，晚到的 AI 结果在退出练习后展示。练习不修改网页原文，不发送或保存练习输入。
- **自动保存**：设置修改约 650 毫秒后自动保存，完成后显示 toast。无效输入或保存失败时保留编辑内容并显示原因。

控制台支持简体中文和英文，默认跟随浏览器语言。界面语言和翻译目标语言独立设置。

## 网站权限和专属配置

默认使用**黑名单模式**：在已授权网页运行，屏蔽的网站除外。展开浮窗中的「网站设置」可屏蔽当前网站；黑名单同时停止该网站上的建议和输入统计。也可在设置中改用白名单模式，仅处理列出的网站。

每个网站可以单独设置默认操作、目标语言、大模型配置或仅机器翻译，以及机器翻译引擎；也可以跟随全局。保存后从下一次建议开始使用。切换网站配置不会自动授权新服务，也不会改变其他网站的全局配置。

密码、支付和可识别的密钥等敏感输入框会跳过。浏览器内部页面和扩展商店等受保护页面无法运行。

这是开发者在发布前提供的共享免费服务。每日额度北京时间 **08:00** 重置；额度耗尽时会提醒并暂停重复 AI 调用，机器翻译仍可使用。服务可能在发布阶段调整或结束。部署与运营方式见[Cloudflare 部署说明](docs/cloudflare-deployment.md)。

**旧版地址迁移**：重新加载扩展，在设置中选中使用旧 workers.dev 地址的 Saywell 配置，点击一次「连接并测试」，即可切换到新地址并重新授权。其他服务商和自定义地址不会被改写。

### 机器翻译

| 引擎 | 使用方式 |
| --- | --- |
| Google 网页翻译、Bing 网页翻译、Microsoft Edge | 内置免密钥适配，属于实验性网页接口，可能受网络、限流或接口变更影响 |
| MyMemory | 免密钥服务，有日用量、IP 和单次长度限制 |
| 浏览器本地翻译 | 浏览器和语言模型可用时优先尝试；是否支持会单独检测 |
| LibreTranslate、Microsoft Azure、Google Cloud | 可自行配置服务端或凭据 |

可以调整回退顺序、关闭回退或停用单个服务。每一跳远程翻译都必须已有文本授权和浏览器端点访问权限；不会自动授权其他服务。

### 自带大模型

支持 OpenAI-compatible、OpenAI、DeepSeek、小米 MiMo、硅基流动、Ollama 和 Gemini。最多保存 20 组配置，每组拥有独立端点、密钥、思考设置和请求上限；选择一组全局激活，也可按网站指定。

选择服务商，填写模型与所需凭据，点击「连接并测试」即可申请端点访问、授权发送文本并执行固定测试句。连接其他配置不会自动将其激活。自带服务的用量和费用由相应服务商决定。

## 配置备份与隐私

### 本地翻译历史

从控制台侧栏或扩展弹窗进入「翻译历史」。默认滚动保留最近 **100 条原文和结果**，机器翻译与 AI 结果合并为同一条记录。可以搜索原文、结果或网站，删除单条、清空全部，或将当前搜索结果导出为 JSON。

保留数量可选 **50／100／200／500／1,000**，也可关闭记录。减少数量会立即清理更早的记录；关闭只停止新记录，已有历史可另行清空。达到本地空间上限时可能提前清理较早记录。页面随滚动加载更多，记录只保存在本机，不包含服务商凭据，也不会混入输入统计或配置备份。

### 配置备份

设置 → 本地数据与隐私 →「配置备份」可导出和导入 JSON。导出前先保存当前有效修改；备份包括全局偏好、大模型配置、网站专属设置、浮窗位置／尺寸和界面语言，**不含 API Key、服务文本授权或练习数据**。

导入前会展示预览；确认后替换配置，保留统计和词汇数据。服务文本授权需重新确认，缺失的网站权限需另行申请。同一配置身份和端点的本机密钥可保留，其他被替换的密钥会移除。

- 远程处理只发送当前输入框文本和任务设置；授权远程服务后，服务商的数据处理规则适用。Google 网页翻译和 MyMemory 等接口使用 URL 查询参数传递文本。
- API Key 默认只保存在浏览器会话中。选择记住时使用**未加密的本地存储**，不会传给网页脚本或写入导出文件。
- 本地练习统计记录数字汇总和网站域名，最多保留 366 天，不保存草稿或按键日志。英文单词量为近似输入计数；中文在输入法提交后计数，不统计候选拼音或取消输入。
- 暂停翻译不等于关闭本地统计；统计可在设置中单独关闭。普通文本框中的所有敏感内容无法可靠自动识别。

## 从源码构建

使用 Node.js **24** 和 npm：

```sh
npm ci
npx playwright install --with-deps chromium
npm run check
npm run package
```

`npm run check` 依次执行 Node 测试、扩展构建和 Chromium 浏览器测试。浏览器测试使用固定测试文本和本地模拟 API。构建输出在 `dist/`，安装包在 `release/saywell-版本号.zip`；`package.json` 与 `manifest.json` 的版本必须一致。

| 命令 | 作用 |
| --- | --- |
| `npm run build` | 构建扩展和本地 logo 资源 |
| `npm run test` | 执行 Node 测试 |
| `npm run test:browser` | 执行 Chromium 扩展测试 |
| `npm run preview` | 打开设计预览；不能处理真实输入或保存扩展设置 |
| `npm run worker:check` | 仅检查 Worker 构建，不部署、不执行模型推理 |
| `npm run worker:deploy` | 手动部署 Cloudflare 后端，需要开发者登录 |

如需使用已有的 Playwright 兼容 Chromium，可将 `INPUT_COACH_BROWSER` 设为其绝对路径。扩展无运行时 npm 依赖，不加载远程脚本。

`npm run check` 也会检查输入、练习 diff、滚动定位和自动建议圆环的性能预算，超限即失败。核心计时可用 `npm run test:performance` 单独运行；数值、测试方式和优化记录见[输入性能与回归预算](docs/performance-review.md)。CI 报告保留测量 JSON，便于比较后续更新。

## 自动构建

每次推送代码、提交 Pull Request 或在 Actions 点击 **Run workflow** 时，会自动：

1. 安装 Node.js 24、锁定的 npm 依赖和 Chromium。
2. 执行完整测试、构建扩展并检查 Worker 打包。
3. 生成并上传扩展 ZIP，在构建详情页的 **Artifacts** 下载，保留 14 天。
4. 保存浏览器测试报告和截图，便于排查失败，保留 7 天。

配置文件：[`.github/workflows/build.yml`](.github/workflows/build.yml)。构建不需要 Cloudflare 密钥，不会自动部署 Worker 或发布扩展商店。
