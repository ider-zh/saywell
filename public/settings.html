01

LLM configurations

Changes save automatically. Activate selects the configuration used on websites. Each configuration has its own key and text authorization.

Thinking is off by default for each configuration. Auto uses the provider protocol; for an unknown compatible endpoint, choose its documented protocol. Models that require reasoning need a different model or thinking enabled.

Service not connected

Connect and test saves and enables this configuration, requests browser access if needed, and allows your input text to be sent to this service. The test sends only “This is a connection test.” Disable service stops future requests. Keys are session-only by default; remembering keys requires an unlocked encrypted vault. Tests count toward the daily request limit. Connecting does not change the active configuration.

04

Website permissions

Blacklist mode is the default: run on granted websites except blocked hosts. Grant all-website access once to avoid enabling sites individually.

In blacklist mode, use the translation card to block the current website. The manual shortcut can reopen its blocked status without sending text. Switch modes without deleting either list.

    Website permission allows input detection and local counters on that site. Provider permission separately allows transmitting the focused draft. Excluded sites are never processed or counted. Password, payment, and recognizable secret fields are skipped. Avoid sensitive drafts in ordinary text fields.

    02

    Writing preferences

    Alt + Shift + E requests a suggestion manually. Set a different shortcut at chrome://extensions/shortcuts (or edge://extensions/shortcuts). Text changes only when you click Apply.

    03

    Translation engines

    No-key quick start

    No account. No API key.

    Enable Google web, Bing web, Microsoft Edge and MyMemory with one click. No account or API key is needed. Your input may be sent to these services when translating or falling back. Web interfaces are experimental and can change; network restrictions and rate limits apply.

    Fallback order & connectivity

    Auto prefers an available on-device model, then this order. A manually selected engine runs first. Only authorized engines with host permission can receive text. Individual engine tests do not use fallback.

      05

      Local data & privacy

      Analytics do not store drafts. AI-applied and pasted text are counted separately. Translation pause does not pause analytics. Vocabulary sentences are saved only when you select the separate consent checkbox. Practice-data exports contain numeric activity and vocabulary definitions; credentials, endpoints, and saved contexts are excluded.

      Local history keeps 100 recent source texts and results in this browser session by default. Create a password-protected vault to retain them after restart. Change the limit, turn recording off or clear it on the history page.
