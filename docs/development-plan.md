## Before public release

- Run ChatGPT, GitHub, Gmail and search scenarios on stable Chrome and Edge, including OS-level Chinese IME and controlled/rich editors.
- Download/prepare Chrome zh→en model with explicit gesture; test isolated-document exposure, local translation and missing-model behavior. Confirm browser/OS/hardware variants and Edge feature availability.
- Test self-hosted LibreTranslate and live user-configured providers including official Azure (and model-specific LLM temperature/token behavior), without bundling credentials. Recheck the experimental Edge browser endpoint before distribution; current anonymous success does not establish a supported third-party API contract.
- Recheck provider terms/quotas, privacy policy and Web Store listing requirements. MyMemory official spec/limits pages were unreachable to the web reader; recheck published terms before distribution.
- Profile long sessions on representative websites; verify tab discard/restore, nested iframes, worker restarts, permission revocation, offline use and quota resets.
- Prepare store assets, accurate permissions/retention disclosures, and manual acceptance sign-off. Publishing/pushing requires explicit authorization.

Deferred optional enhancements: dictionary hints in basic mode, encrypted key handling via an external vault if justified, explicit sentence selection, deeper site-specific editor adapters, a flashcard/review scheduler, monetary token budgets, and richer analytics beyond local practice trends. The sponsored Cloudflare Worker is deployed and optional; MT and user-configured providers remain usable independently.
