# Saywell 隐私政策

更新日期：2026 年 10 月 22 日

Saywell 是网页输入框中的中英翻译、润色和语言练习助手。维护者为 GitHub 用户 ider-zh。项目和支持入口：[Saywell GitHub](https://github.com/ider-zh/saywell)、[问题反馈](https://github.com/ider-zh/saywell/issues)。请勿在公开反馈中粘贴原文、密钥或其他敏感信息。

## 授权和处理范围

安装后，扩展会说明处理方式，并由你点击“同意并启用 Saywell”申请网页访问权限。授权后，在允许的网站输入并停顿时，Saywell 可自动处理当前输入框的完整文本，而不只是最后几个字；每次最多 6,000 个 UTF-16 单位。也可以使用快捷键手动触发。扩展不会主动读取整页正文、浏览器 Cookie 或账户登录信息，不会提交表单、发送消息或自动替换原文；只有点击 Apply 才会尝试替换。

密码框及带有常见敏感字段标识的输入框被排除。但普通文本框中的医疗、金融、商业机密、个人通信或凭证无法可靠识别。请在敏感网站暂停、加入黑名单，或使用仅本地处理方式。你可以撤销网页权限、关闭自动建议或切换到白名单；拒绝所有网站权限后仍可按网站授权。

## 远程处理和接收方

一步授权默认连接 Saywell 免费 AI，由开发者维护的 https://saywell.9992099.xyz 上的 Cloudflare Worker 转交 Cloudflare Workers AI，使用 Qwen3 30B A3B FP8 处理文本。发送内容包括当前草稿、目标语言、任务、风格、难度及输出限制。扩展不会向该服务发送你的 API Key、完整网页 URL、历史记录或词汇列表。Cloudflare 会接触请求来源 IP 和必要的网络元数据；Worker 临时使用 IP 的 SHA-256 摘要进行限流，不把 IP 或文本写入应用日志。安全错误日志仅包含随机请求 ID 和错误码。当前 Worker 关闭观测日志，不配置文本数据库或内容缓存。

Cloudflare 的[Workers AI 数据政策](https://developers.cloudflare.com/workers-ai/platform/data-usage/)规定标准推理请求的内容保留与非训练承诺，并说明运营元数据和法律、安全例外。我们不将草稿出售、用于广告、训练模型或与功能无关的分析，也不提供人工审阅草稿的运营功能。服务商处理仍受其条款约束；这些承诺不意味着所有自选服务都零保留。

机器翻译默认尝试浏览器本地能力，具体取决于浏览器及已准备的语言模型。实验性的 Google 旧网页、Bing 网页和 Microsoft Edge 翻译接口在上架版停用。MyMemory、LibreTranslate、Google Cloud Translation、Microsoft Azure，以及 OpenAI、DeepSeek、Xiaomi MiMo、SiliconFlow、Gemini、Ollama 和兼容服务，只有在你分别配置并连接后才可接收文本。你指定的服务商和端点是实际接收方；请先查看其隐私与保留规则。MyMemory 查询把原文放在 HTTPS URL 的查询参数中，其服务端或网络基础设施可能记录该 URL；它不是默认授权的接收方。

如果你连接了机器翻译和 AI，两路可同时发送当前文本；启用失败回退后，同一文本还可能发送给下一家已授权的机器翻译服务。回退不会授权新服务，也不会自动切换到另一组 LLM。远程端点仅允许 HTTPS；你自行配置的本机服务可使用 localhost HTTP。请求不携带网页 Cookie，禁止重定向并省略 Referer。各服务也会接触必要的连接 IP 等网络元数据。

## 本地记录与加密

历史默认滚动记录最近 100 条成功处理的原文、结果、解释、来源引擎、网站域名、时间、任务和目标语言。可选择 50、100、200、500、1,000 条或关闭，并受总容量限制。不会保存密钥。历史页面提供搜索、删除、清空和手动导出；清空或关闭会拒绝之前尚未完成的写入。

练习统计保存数字汇总和网站域名，最多保留 366 个有记录的日期，不保存逐键日志或草稿。关闭翻译建议不会自动关闭统计；统计有单独开关，临时暂停和网站排除也会阻止对应记录。词汇仅在主动保存时记录；原句语境需要单独勾选。浮窗内重输练习不保存练习内容，也不发送给远程服务。

默认无需保险库密码：历史、统计和词汇以 AES-256-GCM 密文保存在浏览器会话内存；解密密钥也只存在受限制的会话内存，浏览器会话结束，或扩展重新加载、更新、停用后，这些数据消失。API Key 默认也仅保存在受限制的会话内存。

如需跨重启保留，请另行创建本地保险库。保险库使用随机数据密钥进行 AES-256-GCM 加密，通过 PBKDF2-HMAC-SHA-256、随机盐及 600,000 次迭代从你的密码派生包装密钥。磁盘只保存密文、随机盐、随机 IV 及被包装的数据密钥，不保存密码或明文数据密钥。解锁状态仅维持当前浏览器会话；重新加载、更新或停用扩展也会锁定；重启或手动锁定后，私有记录暂停，保存的密钥不可用，免费 AI 仍能工作。“记住密钥”只在保险库已创建并解锁时可用。忘记密码无法找回数据；你可以确认删除保险库重新开始。

升级发现的旧明文历史、词汇和统计会先迁入受限制的加密会话存储；旧明文密钥移入会话内存并取消记住选项，成功后删除旧本地字段。请在关闭浏览器前创建保险库以长期保留迁移数据。加密保护锁定时的本地数据，并不防御已被控制的操作系统、恶意扩展代码或解锁状态下对扩展的完全访问。浏览器外的旧备份或磁盘快照不会被本次迁移追溯清除。

## 配置、导出与删除

语言、服务端点与模型、授权选择、网页名单、浮窗位置和其他非密钥偏好保存在浏览器本地配置中；这些配置不是保险库内容，可能包含你填写的网站域名。没有云同步或遥测上报。

配置导出不含密码、密钥、保险库密文、历史或练习内容。内置 AI 参数随应用更新，备份只保留引用。练习导出不含凭证和保存的原句语境。历史导出是由你主动下载的明文文件，可能包含敏感信息；请妥善保存，Saywell 无法删除你下载或分享的文件。

你可以分别清理历史、统计和词汇，忘记密钥、锁定或删除保险库，并在浏览器中撤销权限。停用历史不会自动删除已有记录。会话记录在浏览器会话结束后消失；保险库记录保留到滚动淘汰、主动删除或卸载，未设置额外按天过期。卸载会删除扩展的浏览器存储。第三方已经收到的文本受其删除、保留与法律义务约束，清空本地数据不会撤回这些请求。

## 用途限制与政策更新

Saywell 对用户数据的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据仅用于用户授权的翻译、润色、配套练习及必要安全运行；不出售、不用于广告画像、信用评估或其他不相关用途，也不允许为这些用途转移数据。

共享免费 AI 有每日额度，可能限流、调整或结束；不承诺无限或永久免费。重要数据处理变更会在扩展内说明，并在需要时重新请求同意。最新政策以项目公布的版本为准。Saywell 不面向未达到当地同意年龄的儿童专门设计或营销。
