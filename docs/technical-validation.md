### No-key fallback update — 2026-10-20

The prior preset had only one ready-to-configure remote no-key provider (MyMemory); LibreTranslate needed an endpoint and Google Cloud needed a key. Manual provider selection also disabled fallback entirely. Either network/quota/500-byte rejection could therefore leave no eligible successful provider. This is an identified limitation, not a confirmed diagnosis of the user's particular machine; no private browser settings or failure logs were supplied.

Added a disclosed experimental Microsoft Edge preset plus a one-click Edge/MyMemory activation, configurable fallback order, a fallback opt-out and connection diagnostics. The current anonymous endpoint is `https://edge.microsoft.com/translate/translatetext?from=zh-CHS&to=en`, POST `["synthetic text"]`. It is not a documented Microsoft third-party API. Its string-array request shape is described by the [translation-hub-sdk author's API documentation](https://github.com/forever-chen/-translation-hub-sdk/blob/main/API.md) and [BabelTower's author documentation](https://github.com/c1375rick/BabelTower/blob/main/README.md); those sources establish observed integration shape, not permission for unlimited/commercial use or future availability. The adapter requests no login, cookies or scraped auth token and can be individually revoked.

- **Actual Chromium MV3 extension worker:** Microsoft Edge, MyMemory and the Auto chain all returned usable English for the fixed phrase `你好，世界。`. This checks extension-origin network behavior, not only Node reachability. Profiles were disposable, and no personal drafts/credentials were used.

There is no universally reliable, unlimited, configuration-free translation service. A supported on-device model needs no LLM configuration. MyMemory and the experimental Edge preset offer observed no-key paths after explicit remote authorization. Fresh installation makes no external calls and requests no website-wide access.

## LLMs

OpenAI, DeepSeek, Ollama, and custom compatible providers use chat/completions adapters. OpenAI uses max_completion_tokens and store:false; other compatible providers use max_tokens. Temperature is optional because not every model supports it. Gemini uses a separate generateContent adapter. Models are user supplied; defaults are examples, not availability promises. Test Connection sends a disclosed synthetic sentence through the same adapter and counts toward the daily local request cap. Cap counts attempted requests, including failures; it is not a monetary billing guarantee.

## Permissions and credentials

MV3 service worker owns network and storage. Website access and provider access are separate application permissions, even when the Chromium origin grant happens to overlap. Register content scripts only on user-selected site origins. Recheck site policy, enable state, consent, and runtime origin permission on each request. Endpoint URL changes invalidate previous consent. HTTPS required except loopback. Redirects are rejected. Raw keys default to storage.session, which survives worker restarts but ends with the browser session; optional storage.local persistence is unencrypted. Storage is restricted to TRUSTED_CONTEXTS. Content scripts receive a redacted settings projection only. Practice-data exports exclude keys, provider configuration, and vocabulary contexts. Separate configuration backups include endpoints and preferences but exclude credentials, text consent and practice data.

## Editor strategy

Native input/textarea replacement uses the native value setter and bubbling input event for controlled React forms. Plain contenteditable and simple ProseMirror/Draft.js structures use selection plus insertText; direct text fallback is limited to unstructured plain editors. Plain Slate uses its model-owned paste/native-input path after selection synchronization. Lexical, Quill, CodeMirror, Monaco and formatted/embedded rich content retain Copy. Every Apply verifies the exact source and connection again, including current policy after asynchronous Slate selection updates. IME text is processed once at compositionend, never during composition. Request sequence IDs invalidate suggestions after edits, blur, pause, or mode changes. No provider HTML is inserted.

## Analytics strategy

Trusted insertion events are counted; typing, paste/drop, and AI Apply use separate counters. Composition commits count once. Deletion, undo/redo, programmatic input, autocomplete replacements, and Apply do not count as independent writing. English is an approximate count of new ASCII word starts, not unique words or final document length. Full snapshots live only in a WeakMap in the page. Persistent data is date/hostname/numeric totals. Site blocklists govern both collection and translation. Translation pause leaves analytics active; a separate analytics switch disables collection.
